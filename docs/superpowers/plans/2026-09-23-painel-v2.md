# Painel v2 (Parte B) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** O painel desktop vira a central do RAGX: grade de projetos com estado real (atualizado, defasado, embeddings faltando, sem hooks), ações que rodam numa fila única, tela de Conexões (RAGX CLI, Claude Code, Ollama no Docker), onboarding na primeira abertura e visual escuro no estilo do Perssua, sem nenhum travessão em texto visível.

**Architecture:** O processo principal do Electron ganha módulos pequenos e testáveis por injeção de dependência: resolução do executável `ragx`, leitura de `.ragx/status.json`, branch atual via `git`, checagens de conexão, fila serial de tarefas e um catálogo fechado que traduz "tipo de tarefa + id de projeto" em argumentos de linha de comando. O renderer nunca manda caminho nem argumento livre: pede ações por tipo e id, e pastas escolhidas pelo usuário viram tokens guardados no processo principal. O renderer é reescrito em telas (Projetos, Detalhe, Conexões, Como funciona, Onboarding) sobre tokens de cor escuros.

**Tech Stack:** Electron 33, React 19, TypeScript 6, Vite 8, Vitest 2 (jsdom), Testing Library, sql.js (fallback), `node:child_process`, `node:http`. Núcleo Python (Task 1): pytest, uv.

```ts
import { execFile } from 'node:child_process'

export type ExecResult = { code: number; stdout: string; stderr: string }
export type ExecFn = (
  file: string,
  args: string[],
  opts?: { cwd?: string; timeoutMs?: number },
) => Promise<ExecResult>

/** Roda um executável com lista de argumentos (nunca shell). Nunca rejeita. */
export const execFileText: ExecFn = (file, args, opts = {}) =>
  new Promise((resolve) => {
    execFile(
      file,
      args,
      { cwd: opts.cwd, timeout: opts.timeoutMs ?? 5000, windowsHide: true, encoding: 'utf-8' },
      (err, stdout, stderr) => {
        if (!err) return resolve({ code: 0, stdout, stderr })
        const e = err as NodeJS.ErrnoException & { code?: number | string; killed?: boolean }
        if (e.killed) return resolve({ code: -1, stdout, stderr: 'tempo esgotado' })
        resolve({ code: typeof e.code === 'number' ? e.code : -1, stdout, stderr: stderr || e.message })
      },
    )
  })
```

`src/app/electron/system/ragx-exe.ts`:

```ts
import fs from 'node:fs'
import path from 'node:path'

let cached: string | null | undefined

export function resetRagxCache(): void {
  cached = undefined
}

interface Deps {
  env?: NodeJS.ProcessEnv
  exists?: (p: string) => boolean
  platform?: NodeJS.Platform
}

/**
 * O app aberto pelo menu Iniciar herda o PATH do Explorer, que pode não ter
 * a pasta onde o instalador do RAGX pôs o executável. Por isso, além do PATH,
 * olha os locais conhecidos de instalação (uv tool / pipx).
 */
export function resolveRagx(deps: Deps = {}): string | null {
  const env = deps.env ?? process.env
  const exists = deps.exists ?? ((p: string) => fs.existsSync(p))
  const platform = deps.platform ?? process.platform
  const win = platform === 'win32'
  const sep = win ? ';' : ':'
  const exts = win ? (env.PATHEXT ?? '.EXE;.CMD;.BAT').split(';').filter(Boolean) : ['']

  for (const dir of (env.PATH ?? env.Path ?? '').split(sep).filter(Boolean)) {
    for (const ext of exts) {
      const candidate = path.join(dir, `ragx${ext}`)
      if (exists(candidate)) return candidate
    }
  }
  const home = win ? env.USERPROFILE : env.HOME
  if (home) {
    const candidate = path.join(home, '.local', 'bin', win ? 'ragx.exe' : 'ragx')
    if (exists(candidate)) return candidate
  }
  return null
}

export function ragxCommand(): string {
  if (cached === undefined) cached = resolveRagx()
  return cached ?? 'ragx'
}
```

```ts
import { execFileText, type ExecFn } from '../system/exec'

export interface GitHead {
  branch: string | null
  commit: string
}

/** `--no-optional-locks`: o painel consulta a cada ciclo e não pode disputar o .git/index com o usuário. */
export async function readGitHead(projectPath: string, exec: ExecFn = execFileText): Promise<GitHead | null> {
  const head = await exec('git', ['--no-optional-locks', 'rev-parse', 'HEAD'], { cwd: projectPath })
  if (head.code !== 0 || !head.stdout.trim()) return null
  const ref = await exec('git', ['--no-optional-locks', 'symbolic-ref', '--quiet', '--short', 'HEAD'], {
    cwd: projectPath,
  })
  return { branch: ref.code === 0 && ref.stdout.trim() ? ref.stdout.trim() : null, commit: head.stdout.trim() }
}
```

```ts
export function readStatusFile(projectPath: string): StatusFile | null {

    const raw = fs.readFileSync(path.join(projectPath, '.ragx', 'status.json'), 'utf-8')
    const data = JSON.parse(raw) as StatusFile

    return null
  }
}
```

  Ordem de decisão (a primeira que casar vence):
  1. `!p.exists` → `missing`
  2. `p.running !== null || busyIds.has(p.id)` → `indexing`
  3. `p.counts === null || p.lastError !== null` → `error`
  4. `p.counts.pendingEmbeddings > 0` → `embeddings`
  5. `p.index === null` → `stale` (nunca indexou com o RAGX novo)
  6. `p.git && (p.index.commit !== p.git.commit || (p.index.branch !== null && p.git.branch !== null && p.index.branch !== p.git.branch))` → `stale`
  7. `p.hooksInstalled === false` → `no-hooks`
  8. → `ok`

```ts
function files(dir: string): string[] {

    if (e.isDirectory()) return e.name === '__tests__' || e.name === 'test' ? [] : files(full)
    return /\.(tsx?|css|html)$/.test(e.name) ? [full] : []
  })

/** Remove comentários // e /* */ (TS/CSS) e <!-- --> (HTML) antes de procurar. */
function stripComments(src: string): string {
  return src

    .replace(/<!--[\s\S]*?-->/g, '')
    .replace(/(^|[^:\\])\/\/.*$/gm, '$1')

  })
})
```
